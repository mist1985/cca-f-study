# 4.4 · Check + retry

📍 **Map:** Whole picture → 4. Answers → **4.4 Check + retry**  ·  ⏱ 3 min

## The one rule
> Retry **with the exact error**. But if the info **isn't in the document**, retrying is useless.

## Picture it
The form is perfect, but the items add up to €940 and the total says €1,040. Your code catches it and asks again, saying exactly what's wrong.

## Know these 🎯
- Two kinds of errors:
  - **Syntax/schema** (broken JSON) → removed by tool use (4.3).
  - **Semantic** (doesn't add up, wrong field) → **your validation code** (e.g. Pydantic) + retry.
- A good retry sends: **original document + failed extraction + the specific errors.**
- Retry **works** for: format mismatches, structural mistakes.
- Retry **fails** when: the info is **absent**, or only in **another document not provided**.
- Self-check fields: extract `calculated_total` **and** `stated_total` + a `conflict_detected` flag.
- Feedback loop: add a **`detected_pattern`** field to findings → see which patterns developers dismiss → fix those.

## 👀 What it looks like
```python
for attempt in range(3):
    data = extract(doc, feedback)
    errors = validate(data)              # e.g. sum(line_items) != stated_total
    if not errors:
        break
    feedback = (f"<document>{doc}</document>"
                f"<previous_extraction>{data}</previous_extraction>"
                f"<errors>{errors}</errors>"
                "Fix only these errors. If a value is not in the document, use null.")
```
Self-checking schema fields:
```json
{"stated_total": 1040.00, "calculated_total": 940.00, "conflict_detected": true}
```
**Piece by piece**
- The retry carries **document + failed output + exact errors**. Not the same prompt again.
- Bounded attempts. Absent info → `null`, not more pressure.
- `conflict_detected` flags a real mismatch **in the source** for a human, instead of hiding it.

## 🧩 Connects to
4.3 (schema = shape) · 5.5 (route conflicts to humans) · 4.1 (`detected_pattern` feedback loop)

## ⚠️ Exam traps
| ❌ Wrong | ✅ Right |
|---|---|
| Retry the same prompt unchanged | Add the specific errors |
| Retry until the tax ID appears | It's absent: null + flag |

<details><summary>🧠 Say it out loud: when will a retry NOT help?</summary>

When the information isn't in the document Claude was given.
