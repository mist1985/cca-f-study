# 2.3 · Who gets which tools + `tool_choice`

📍 **Map:** Whole picture → 2. Tools → **2.3 Who gets which tools**  ·  ⏱ 3 min

## The one rule
> **Each agent gets only the tools its job needs.** Fewer tools = better choices.

## Picture it
You don't give every employee keys to every room. A writer with a web browser starts browsing instead of writing.

## Know these 🎯
- 18 tools instead of 4–5 → **worse tool choice**.
- Agents misuse tools outside their job (a synthesis agent doing web searches).
- Replace a broad tool with a **narrow** one: `fetch_url` → `load_document` (checks it's a document URL).
- **Scoped cross-role tool** for frequent simple needs: give the synthesis agent a small `verify_fact` tool. Complex checks still go through the lead.

## `tool_choice` (memorize this table)
| Setting | Means |
|---|---|
| `"auto"` | Claude *may* call a tool, or just reply in text |
| `"any"` | Claude **must** call a tool (any one) |
| `{"type":"tool","name":"x"}` | Claude **must** call tool **x** |

- `"any"` → guarantees a tool call instead of a chatty text reply.
- Forced tool → makes sure **one specific tool runs first** (e.g. `extract_metadata` before enrichment). Later steps go in the next turns.

## ⚠️ Exam traps (this is sample question #9)
| ❌ Wrong | ✅ Right |
|---|---|
| Give the synthesis agent all web tools | A scoped `verify_fact` tool (85% case) |
| `auto` guarantees a tool call | Only `any` or forced do |

<details><summary>🔬 Real-world note (NOT the exam answer)</summary>

The newest models reject forced `any`/`tool` (error 400). On the exam, follow the guide: `any` and forced selection are valid answers.
</details>

<details><summary>🧠 Say it out loud: which setting makes one specific tool run first?</summary>

`tool_choice: {"type": "tool", "name": "..."}` (forced selection).
</details>
