# 2.4 · MCP for a team

📍 **Map:** Whole picture → 2. Tools → **2.4 MCP for a team**  ·  ⏱ 3 min

## The one rule
> Team-shared servers → **project `.mcp.json`** with secrets as **`${VARIABLES}`**.

## Picture it
MCP = USB for AI. Plug in a "server" (GitHub, Jira, a database) and Claude gets its tools. Question: where do you save the plug settings so the whole team gets them, without leaking passwords?

## Know these 🎯
| Where | Who gets it | Use for |
|---|---|---|
| `.mcp.json` (project, in git) | whole team | shared tooling |
| `~/.claude.json` (user) | only you | personal / experiments |

- `${GITHUB_TOKEN}` in `.mcp.json` → each person's own token fills it in. No secret in git.
- Tools from **all** configured servers are found at connection time and are **all available at once**.
- **Resources** = read-only catalogs (issue lists, docs, database schemas). They show Claude what exists, **without** exploratory tool calls.
- Claude uses built-in Grep instead of your better MCP tool? → **Improve the MCP tool's description.**
- Standard system (Jira, GitHub)? → use an **existing community server**. Build custom servers only for team-specific workflows.

## 👀 What it looks like
`.mcp.json` at the project root (committed to git):
```json
{
  "mcpServers": {
    "github": {
      "type": "http",
      "url": "https://api.githubcopilot.com/mcp/",
      "headers": {"Authorization": "Bearer ${GITHUB_TOKEN}"}
    },
    "jira": {
      "command": "npx", "args": ["-y", "<existing-community-jira-server>"],
      "env": {"JIRA_API_TOKEN": "${JIRA_API_TOKEN}"}
    }
  }
}
```
Using a resource instead of exploratory calls:
```
@postgres:schema://orders   → the table schema is put straight into context
```
**Piece by piece**
- In git = the whole team gets the same servers.
- `${GITHUB_TOKEN}` = each developer's **own** token, from their environment. No secret in git.
- Both servers' tools are available **at the same time**.
- Personal/experimental servers go in `~/.claude.json` instead.

## ⚠️ Exam traps
| ❌ Wrong | ✅ Right |
|---|---|
| Real token written in `.mcp.json` | `${GITHUB_TOKEN}` |
| Team server in your user config | Project `.mcp.json` |
| Build your own Jira server | Use the community one |
| Many tool calls to discover the DB schema | Expose it as an MCP **resource** |

<details><summary>🧠 Say it out loud: how does the team share a server without sharing a password?</summary>

Commit `.mcp.json` with `${TOKEN}` placeholders. Each person sets their own environment variable.
