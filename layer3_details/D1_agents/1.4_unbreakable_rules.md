# 1.4 · Unbreakable rules + handing over to a human

📍 **Map:** Whole picture → 1. Agents → **1.4 Unbreakable rules**  ·  ⏱ 3 min

## The one rule
> Must never break → **a lock in code**. Hand to a human → **a short structured summary**.

## Picture it
Rule: "never refund before confirming the customer". Claude obeys 99 of 100 times. The 100th time, a scammer gets €500. So you install a lock.

## Know these 🎯
- Instructions alone have a **non-zero failure rate**. Code locks (hooks, prerequisite gates) don't.
- Classic exam example: **block `process_refund` until `get_customer` has returned a verified customer ID.**
- Customer asks about 3 things at once → split into 3 items, **investigate in parallel**, then give one combined answer.
- Handover to a human who **can't see the chat**: customer ID + root cause + refund amount + recommended action.

## 👀 What it looks like
A prerequisite gate in code:
```python
def before_tool(name, tool_input, session):
    if name in ("lookup_order", "process_refund"):
        if session.get("verified_customer_id") is None:
            return block("Call get_customer and verify identity first.")
    return allow()
```
A structured handoff to a human:
```json
{"customer_id": "C-1029", "issue": "double charge on order 4821",
 "root_cause": "payment retried after timeout", "refund_amount": 12.50,
 "recommended_action": "refund the second charge", "attempted": ["lookup_order", "get_payments"]}
```
**Piece by piece**
- The gate runs **every time**, in code. Claude can't talk its way past it.
- The block message tells Claude **what to do instead**.
- The handoff is short and complete. The human never needs the transcript.

## ⚠️ Exam traps (this is sample question #1)
| ❌ Wrong | ✅ Right |
|---|---|
| Stronger wording in the system prompt | Code blocks the refund until ID is verified |
| Few-shot examples showing the right order | Still just probabilistic |
| A classifier that limits which tools are available | Controls *which* tools, not the *order* |
| Send the human the whole transcript | Short structured summary |

<details><summary>🔬 Bonus (beyond the official guide)</summary>

Hook exit codes: 0 = OK · **2 = block** · anything else (incl. 1) = warning only, action still runs.
</details>
