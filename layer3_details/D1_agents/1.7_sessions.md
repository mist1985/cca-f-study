# 1.7 · Sessions: resume & fork

📍 **Map:** Whole picture → 1. Agents → **1.7 Sessions**  ·  ⏱ 3 min

## The one rule
> A session saves the **conversation**, not the **world**. Old tool results can be stale.

## Picture it
A saved game that remembers the chat but not the files. If code changed overnight, Claude's memories are out of date.

## Know these 🎯
- `--resume <session-name>` = continue a **named** session.
- `fork_session` = branch from a shared starting point to **compare two approaches** (e.g. two testing strategies).
- Pick the right option:
  - Earlier context **mostly still valid** → **resume**.
  - Tool results are **stale** → **start fresh with a structured summary**. That's more reliable.
- After resuming: tell Claude **which files changed**, so it re-checks just those. Not a full re-exploration.

## 👀 What it looks like
```bash
claude --resume refund-investigation          # continue a named session
```
```python
# Agent SDK: branch from a shared analysis to try two approaches
options_a = ClaudeAgentOptions(resume=session_id, fork_session=True)
options_b = ClaudeAgentOptions(resume=session_id, fork_session=True)
```
Telling a resumed session what changed:
```
Since we last talked, src/billing/refund.py and src/billing/retry.py changed
(retry logic rewritten). Re-check only those two files; the rest still holds.
```
**Piece by piece**
- `--resume <name>` continues where you left off, with all the old context.
- `fork_session` makes **independent branches**. The original stays untouched.
- A **targeted** "these files changed" message beats re-exploring everything.

## ⚠️ Exam traps
| ❌ Wrong | ✅ Right |
|---|---|
| Resume a week-old session after a big refactor | Fresh session + summary |
| Re-explore the whole codebase after resuming | Tell it the specific changed files |

<details><summary>🔬 Bonus (beyond the official guide)</summary>

`--continue` = latest session. Forks don't undo file edits (checkpoints do).
</details>

<details><summary>🧠 Say it out loud: when is a fresh start better than resume?</summary>

When the old tool results are stale (the files changed). Start fresh and pass in a structured summary.
</details>
