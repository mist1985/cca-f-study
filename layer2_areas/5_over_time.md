# ⏳ Layer 2 · Area 5: Staying Reliable Over Time (15%)

📍 **Map:** Whole picture → **5. Over time** = *keeping it all safe as it runs for hours and grows*

---

## In one sentence

> **Convenient summaries hide problems.** Keep the exact, sourced, structured version.

## 4 ways problems hide

```
 A summary       → blurs exact numbers     → keep a facts block
 An average      → hides a weak area       → measure each group
 A vague error   → hides what broke        → report it in detail
 A long context  → loses the middle        → key facts first, helpers, files
```

## The 6 pieces (each one = a Layer 3 card)

| # | Piece | One line |
|---|---|---|
| 5.1 | Keep exact facts | A case facts block that's never summarized. |
| 5.2 | When to call a human | Asked · policy gap · stuck. Not mood, not confidence. |
| 5.3 | Honest failures | Structured error. Don't hide it, don't kill everything. |
| 5.4 | Big codebases | Helpers + scratchpad files + manifests + `/compact`. |
| 5.5 | Human checks | Accuracy per type and field. Sample high-confidence items too. |
| 5.6 | Sources | Claim → source. Conflicts: show both with dates. |

## The trap in this area

❌ "97% accurate overall, so switch off human checks."
✅ "Check accuracy for each document type and field first."
