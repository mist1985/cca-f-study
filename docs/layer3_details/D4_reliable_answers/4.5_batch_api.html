4.5 Message Batches API

📍 Map: Whole picture → 4. Answers → 4.5 Batch API · ⏱ 3 min

The one rule

50% cheaper, up to 24 h, no guaranteed time. Only for work nobody is waiting on.

Picture it

Economy post: half price, arrives within 24 hours, in no particular order.

Know these 🎯

✅ Good fit❌ Bad fit
Overnight reportsBlocking pre-merge check
Weekly auditsLive chat
Nightly test generationAnything a person waits on
  • custom_id matches each answer to its request (answers come back in any order).
  • No multi-turn tool calling inside one batch request. Your tool can't run halfway through.
  • Failures → resubmit only the failed ones (by custom_id), fixed (e.g. split documents that were too long).
  • Test the prompt on a sample first → fewer expensive resubmits.
  • SLA maths: processing can take 24 h. To promise results in 30 h, submit every 4 hours (wait up to 4 h + 24 h processing ≤ 30 h, with a buffer).
