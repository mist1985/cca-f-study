2.5 Built-in tools

📍 Map: Whole picture → 2. Tools → 2.5 Built-in tools · ⏱ 3 min

The one rule

Grep = search INSIDE files. Glob = find files by NAME. Search first, then read only what matters.

The toolbox 🎯

ToolJobExample
Grepsearch file contentswho calls parseInvoice? where's this error message?
Globmatch file paths**/*.test.tsx
Readload a whole file
Writewrite a whole file
Editchange one unique piece of text
Bashrun commands

Know these 🎯

  • Edit fails because the text isn't unique → Read + Write (fallback in the official guide).
  • Explore step by step: Grep finds the entry point → Read follows the imports. Don't read every file up front.
  • Wrapper modules: first list all exported names, then Grep for each name.

⚠️ Exam traps

❌ Wrong✅ Right
Glob to find who calls a functionGrep
Grep to find all test filesGlob
Read the whole repo firstSearch first, read selectively
🔬 Real-world note

In current Claude Code you can also add surrounding context or use replace_all: true. On the exam, the expected fallback is Read + Write.

🧠 Say it out loud: Edit says "text not unique". Exam answer?

Read the full file, then Write the corrected version.
