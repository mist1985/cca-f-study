1.5 Hooks: the two guards

📍 Map: Whole picture → 1. Agents → 1.5 Hooks · ⏱ 3 min

The one rule

Before the tool = block the call. After the tool (PostToolUse) = clean up the result.

Picture it

Two guards at a door. The guard before can stop someone going in. The guard after can only tidy up what comes out.

Know these 🎯

  • Interception hook (before): blocks policy breaks, e.g. refund over $500 → block and redirect to human escalation.
  • PostToolUse (after): changes results before Claude sees them. Classic: different tools return dates as Unix timestamps, ISO 8601, numeric status codes → normalize to one format.
  • Hooks = guaranteed (deterministic). Prompts = probably (probabilistic).
  • Business rule needs a guarantee → hook.

👀 What it looks like

async def block_big_refunds(input_data, tool_use_id, context):      # BEFORE the tool
    if input_data["tool_input"].get("amount", 0) > 500:
        return {"hookSpecificOutput": {"hookEventName": "PreToolUse",
                "permissionDecision": "deny",
                "permissionDecisionReason": "Over $500: call escalate_to_human instead."}}
    return {}

async def normalize_dates(input_data, tool_use_id, context):        # AFTER the tool
    clean = to_iso8601(input_data["tool_response"])   # 1729425600 → "2024-10-20"
    return {"hookSpecificOutput": {"hookEventName": "PostToolUse",
                                   "updatedToolOutput": clean}}

hooks = {"PreToolUse":  [HookMatcher(matcher="process_refund", hooks=[block_big_refunds])],
         "PostToolUse": [HookMatcher(matcher="^mcp__", hooks=[normalize_dates])]}

Piece by piece

  • The first hook denies the call before it happens, and redirects to escalation.
  • The second rewrites the result so Claude only ever sees one date format.
  • matcher = which tool names the hook applies to.

⚠️ Exam traps

❌ Wrong✅ Right
Block a refund in PostToolUseToo late, it already ran. Block before
Tell Claude in the prompt to convert datesPostToolUse hook normalizes them
Prompt: "never refund over $500"Hook blocks it and escalates
🔬 Bonus (beyond the official guide)

PreToolUse decisions: allow / deny / ask / defer. Several hooks disagree → deny > defer > ask > allow. Matchers match tool names only. Fields go inside hookSpecificOutput.

🧠 Say it out loud: 3 MCP tools return dates in 3 formats. Fix?

A PostToolUse hook converts them all to one format before Claude reads them.
