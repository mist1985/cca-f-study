How to use this guide

How to use this folder

You go from the whole picture to the details, one layer at a time.

Layer 1  →  1 page. The whole exam.               (read first, 5 min)
Layer 2  →  5 pages. One per area.                (~5 min each)
Layer 3  →  30 small cards. One per exam topic.   (~3 min each)
Layer 4  →  practice: questions, mock exam, hands-on, the plan to 90%.
📖 Glossary · 🎯 Quiz (148 questions + 60-question mock) · 🃏 Flashcards

Rules

  1. Don't open Layer 2 until Layer 1 feels obvious.
  2. Every page starts with a 📍 line. It tells you where the piece fits on the map.
  3. Lost? Go back up one layer. The map is always there.
  4. One card = one sitting. Close the file when you finish it. That's a win.
  5. 🔬 "Bonus" sections are optional. They're not in the official exam guide. Skip them on low-energy days.

Order

  • 🗺️ Layer 1 · The Whole Picture
  • 🤖 Layer 2 · Area 1: Agents (27%, the biggest) → files 1 to 5
  • 1.1 · The loop → folders D1 to D5, cards in number order (1.1 … 5.6 = the official task list)
  • ⚠️ Exam answer vs current product docs → 1, 2, 3

Source of truth: Anthropic's official exam guide (v1.0, July 2026), from the official exam page.
Every card is checked against it. Where the exam and today's product docs disagree, the cards give the exam answer (see ⚠️ Exam answer vs current product docs).
