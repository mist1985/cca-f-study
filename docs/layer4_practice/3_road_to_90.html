Honest truth first

Nobody can guarantee a score. Here's what does work: cover every official task statement (this folder does), then prove you're ready with timed practice before booking.

The pass mark is 720/1000 (scaled). The score report shows % correct per area. Aim for 90% in each area, not just overall. (Same lesson as card 5.5: an average hides a weak spot.)

Why step 6 matters most

The guide's sample questions show exactly how the exam thinks. The most common pattern:

3 options sound reasonable. 1 fixes the root cause in the simplest structural way.

Exam-day method (2 min per question)

  1. Which scenario? → which areas apply.
  2. Find the key word: guarantee / must → code · first step → simplest root-cause fix · overnight → batch.
  3. Cross out: "tell Claude to…", "bigger model", "confidence score", "sentiment".
  4. Multiple response → judge each option on its own.
  5. Stuck after 2 min → pick, flag, move on. Never leave one blank.
